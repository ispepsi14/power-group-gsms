# ขั้นตอนตั้งค่า Firebase — POWER GROUP GSMS

เอกสารนี้ทำครั้งเดียวจบ ใช้เวลาประมาณ 10-15 นาที
**ขั้นตอนนี้ยังไม่ต้องผูกบัตรเครดิต**

สิ่งที่ต้องมี: บัญชี Google (Gmail) และคอมพิวเตอร์ 1 เครื่อง

---

## ตอนที่ 1 — สร้างโปรเจกต์

1. เปิด https://console.firebase.google.com
2. ล็อกอินด้วยบัญชี Google ของคุณ
3. กด **Create a project** (หรือ "สร้างโปรเจกต์")
4. ตั้งชื่อโปรเจกต์ว่า `power-group-gsms`
   - ถ้าระบบบอกว่าชื่อซ้ำ ให้เติมตัวเลขต่อท้าย เช่น `power-group-gsms-01`
5. หน้าถัดไปจะถามเรื่อง **Google Analytics**
   - **ปิด** สวิตช์นี้ได้เลย เราไม่ได้ใช้ (ถ้าเปิดไว้ก็ไม่เสียหาย แต่ปิดจะเร็วกว่า)
6. กด **Create project** แล้วรอสักครู่ จนขึ้น **Continue**

---

## ตอนที่ 2 — เปิดระบบล็อกอิน

1. เมนูซ้ายมือ เลือก **Build** → **Authentication**
2. กด **Get started**
3. เลือกแท็บ **Sign-in method**
4. ในรายการ เลือก **Email/Password**
5. เปิดสวิตช์ **Enable** อันแรก
   - ข้างล่างจะมี "Email link (passwordless sign-in)" — **ไม่ต้องเปิด**
6. กด **Save**

> ระบบนี้จะไม่เปิดให้ใครสมัครเองได้ บัญชีทั้งหมดคุณเป็นคนสร้างให้จากหน้านี้

---

## ตอนที่ 3 — สร้างฐานข้อมูล

1. เมนูซ้ายมือ เลือก **Build** → **Firestore Database**
2. กด **Create database**
3. **เลือกที่ตั้งเซิร์ฟเวอร์ (Location)** — เลือก **`asia-southeast1 (Singapore)`**
   - ข้อนี้สำคัญ เพราะสิงคโปร์ใกล้ไทยที่สุด ทำให้เร็วที่สุด
   - **เลือกแล้วเปลี่ยนทีหลังไม่ได้** ถ้าไม่แน่ใจให้ถ่ายรูปหน้าจอส่งมาถามก่อน
4. เลือกโหมด **Start in production mode** (โหมดปลอดภัย)
   - ถ้าเลือก test mode ข้อมูลจะเปิดให้ใครก็เข้าถึงได้ ห้ามใช้
5. กด **Create** / **Enable**

---

## ตอนที่ 4 — ขอรหัสเชื่อมต่อ (สำคัญที่สุด)

1. กดรูป **เฟือง ⚙️** มุมซ้ายบน (ข้างคำว่า Project Overview) → **Project settings**
2. เลื่อนลงมาล่างสุด หมวด **Your apps**
3. กดไอคอน **`</>`** (เว็บ)
4. ช่อง App nickname ใส่ `GSMS`
5. **ไม่ต้องติ๊ก** "Also set up Firebase Hosting" (เดี๋ยวค่อยทำ)
6. กด **Register app**
7. จะขึ้นกล่องโค้ดหน้าตาประมาณนี้ —

```js
const firebaseConfig = {
  apiKey: "AIzaSy........................",
  authDomain: "power-group-gsms.firebaseapp.com",
  projectId: "power-group-gsms",
  storageBucket: "power-group-gsms.appspot.com",
  messagingSenderId: "123456789012",
  appId: "1:123456789012:web:abcdef1234567890"
};
```

**ก๊อปตั้งแต่ `const firebaseConfig = {` ถึง `};` แล้วส่งมาให้ผมทั้งก้อน**

---

## เรื่องความปลอดภัยของรหัสชุดนี้

รหัสชุดนี้**ไม่ใช่รหัสลับ** ทุกเว็บที่ใช้ Firebase จะมีรหัสนี้เปิดเผยอยู่ในหน้าเว็บอยู่แล้ว
ความปลอดภัยจริงมาจาก 2 อย่างที่ผมจะตั้งให้ในขั้นถัดไป:

- **Security Rules** — กฎฝั่งเซิร์ฟเวอร์ ว่าใครอ่าน/เขียนอะไรได้บ้าง
- **บัญชีผู้ใช้** — ไม่มีบัญชี = เข้าไม่ได้เลย

สิ่งที่**ห้ามส่งให้ใคร**คือ *Service account key* (ไฟล์ .json ในแท็บ Service accounts) — อันนั้นคือกุญแจผีที่ข้ามกฎทุกข้อได้ ผมไม่ต้องใช้ และคุณไม่ควรส่งให้ใครทั้งนั้น

---

## ส่งอะไรมาบ้าง

1. โค้ด `firebaseConfig` จากตอนที่ 4
2. รายชื่อพนักงานที่จะสร้างบัญชีให้ — ชื่อเล่น + หน้าที่ เช่น

   | ชื่อ | อีเมลที่จะใช้ล็อกอิน | สิทธิ์ |
   |------|----------------------|--------|
   | เป๊ปซี่ | pepsi.manage1@gmail.com | Admin |
   | ช่างเอ | changa@powergroup.local | พนักงาน |
   | ช่างบี | changb@powergroup.local | พนักงาน |

   > อีเมลไม่จำเป็นต้องเป็นอีเมลจริงที่เปิดได้ ใช้เป็นแค่ชื่อล็อกอินก็พอ
   > (ลงท้าย `@powergroup.local` ได้เลย) แต่ถ้าอยากให้พนักงานกด "ลืมรหัสผ่าน" เองได้
   > ต้องใช้อีเมลจริง

---

## ขั้นต่อไป (ผมทำให้)

- ตั้ง Security Rules — Admin แก้ได้ทุกอย่าง / พนักงานรับรถ เปลี่ยนสถานะ ใส่ราคาได้ แต่ลบงานและเข้าหน้าตั้งค่าไม่ได้
- เพิ่มหน้าล็อกอินเข้าไปในแอป
- เปลี่ยนระบบบันทึกให้ซิงค์ทุกเครื่องแบบเรียลไทม์
- นำข้อมูลรุ่นรถ/อะไหล่/ราคา ที่ทำไว้แล้วเข้าระบบใหม่ทั้งหมด
- เอาแอปขึ้นเว็บ แล้วสอนวิธีติดตั้งลงหน้าจอโฮมของ iPhone/iPad
